# P-09 Costing, quote and release

Building block 5. Engine stage 6 (spec E-06).

Steps
1. Build cost lines: materials (consumed quantity × unit price, or charged packs: Q-K02), consumables, labour, device time, external services, overhead, margin (types used: Q-K01).
2. Aggregate per plate, batch, project (allocation: Q-K01).
3. Generate quote (O9) from the project cost (positions: Q-K05), validity date, payment terms.
4. Customer accepts → project accepted: freeze snapshots.
5. Release: hard reservations, confirmed device bookings, order list lines → P-07, tasks visible in daily list.

Output: cost sheet (O8), quote (O9), released project.
